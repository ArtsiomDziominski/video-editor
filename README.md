# Claude Видеоредактор

Локальный редактор проектов вертикальных роликов (TikTok 9:16): правка озвучки, текстов на экране и таймингов,
мгновенное превью кадра и сборка MP4. Всё работает на вашем компьютере, ролики и голос никуда не загружаются.

## Проект — один файл `.vproj`

Это zip со всем роликом:

| Внутри | Что это |
|---|---|
| `project.json` | шаблон, сценарий (сцена · эмоция · фраза), тексты на экране, сдвиги событий, выбранные дубли, громкость эффектов |
| `voice/voice.wav` | образец голоса для клонирования (VoxCPM2) |
| `voice/lines/` | все дубли озвучки, готовые фразы, `lines.json` (тайминги слов), `takes.json` (что слышит Whisper) |

Файл можно переносить на другой компьютер. Кэш сборки (`build/`) в него не входит и пересобирается сам.

## Запуск

**Двойной клик** по `run_editor.bat` — редактор откроется в своём окне «Claude Видеоредактор» (не в браузере)
с последним проектом. **Перетащите** `.vproj` на `run_editor.bat`, чтобы открыть именно его. Закрыли окно — редактор
выключился.

Из командной строки:

```bash
py -m claude_video_editor.app путь\к\проекту.vproj
```

**Установка** командой `claude-video-editor` (в то же окружение Python, где стоят VoxCPM2 и PyTorch с CUDA):

```bash
pip install -e .
```

Параметры: `--browser` — открыть во вкладке браузера вместо окна, `--no-browser` — только сервер, `--port 8765` — порт.

## Как пользоваться

- Сверху — превью кадра и плеер, снизу — шкала времени с дорожками **Сцены**, **Тексты на экране**, **Озвучка**, **Эффекты**.
- **Нажмите на элемент на шкале** — слева выедет панель с его настройками. Метки текстов и эффектов можно
  **перетаскивать** по времени. Масштаб шкалы — ползунок справа или Ctrl + колёсико.
- Кнопки вверху: формат TikTok 9:16 / YouTube 16:9, «Проект» (название, имя видео, громкость эффектов),
  «Сохранить» и «Экспорт MP4». Прогресс задач и журнал — значок справа вверху.
- Клавиши: пробел — играть / пауза, ← → — на секунду (Shift — на 0.1 с), Ctrl+S — сохранить, Esc — закрыть панель.

## Что можно делать

- **Озвучка.** Текст и эмоция каждой фразы. «Переозвучить» генерирует только эту фразу; «+4 дубля» — ещё варианты.
  Каждый дубль можно прослушать и выбрать вручную. Ударение — заглавной гласной: `дрЕвко`, `свечИ`.
- **Формат.** TikTok / Reels / Shorts — 9:16, 1080×1920 или YouTube — 16:9, 1920×1080. Для горизонтального кадра
  у шаблона своя раскладка (график крупно слева, заголовки и субтитры справа); имя видео меняется на `_youtube.mp4`.
- **Тексты.** Заголовок, кнопки, крупное слово, пункты правила, надпись про следующий выпуск, громкость эффектов,
  имя готового видео. Длинный текст сам уменьшается по ширине.
- **Тайминги.** События привязаны к словам озвучки; сдвиг в секундах в таблице или перетаскиванием метки на шкале.
  Звуковой эффект события едет вместе с ним.
- **Превью.** Клик по шкале — кадр в этот момент; «Играть» — звук с черновым превью кадров.
- **Сборка.** «Собрать звук» и «Собрать MP4» (1080×1920, 60 fps, H.264 + AAC). Видео кладётся рядом с файлом проекта.
- **Сохранить проект** записывает все изменения обратно в `.vproj`.

## Шаблоны

- `chalk_quiz` — «Угадай свечу» на школьной доске: древко и флаг, отсчёт, ответ, правило, губка и бесшовная петля.

Шаблон задаёт структуру сцен; редактор меняет параметры внутри неё. Новые сцены и другие формы графика добавляются
в код шаблона (`claude_video_editor/templates/<шаблон>/audio.py` и `video.py`).

## Требования

- Windows, Python 3.10+, видеокарта NVIDIA (для озвучки и Whisper).
- Пакеты из `pyproject.toml`, включая `voxcpm` и PyTorch с CUDA.
- Шрифт Segoe Print (есть в Windows).
